# 功能说明

## 画布与节点

- 无限画布、多画布工程、网格和视野定位。
- 图片、文本、思维导图、分组、视频、3D 模型、文档、PDF 和表格节点。
- 多选、分组、层级调整、等比例缩放和跨画布复制粘贴。
- 思维导图子节点及连接线。

## 涂鸦

- 自由画笔、压感、颜色和粗细。
- 箭头、空心矩形和空心圆形。
- 撤销上一条涂鸦和清除当前画布全部涂鸦。
- 涂鸦保存在对应画布中，始终位于内容上层，不参与 PNG 导出。

## 素材格式

- 图片：PNG、JPG/JPEG、WebP、BMP、GIF、ICO、TIFF、TGA、DDS、HDR、EXR、AVIF、QOI、PSD、PSB。
- 模型：OBJ、FBX、GLB、GLTF。
- 视频：MP4、WebM 以及系统 WebView 能够解码的其他常见格式。
- 文档：TXT、Markdown、RTF、DOC、DOCX、PDF、CSV、TSV、XLS、XLSX。

## 工程、缓存和恢复

- 工程资源打包保存，可移动到其他目录或电脑。
- 每个工程可以指定独立图片缓存目录，工程内所有画布共享该目录。
- 视口按需加载、缩略图与解码预览持久缓存、原始素材变化自动失效。
- 缓存目录故障时自动回退到系统目录，不阻断图片显示。
- 原子工程保存和后台崩溃恢复副本。

## AI

- 独立配置内容分析模型与图片生成模型。
- 支持 Ollama、OpenAI 兼容接口、豆包和自定义 HTTP 服务。
- 将选中节点上下文发送给分析模型，并将回复写回文本或思维导图节点。
- 将生成的图片插入当前画布，并可与参考节点自动建立连接。
