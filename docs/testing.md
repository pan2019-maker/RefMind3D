# 测试清单

## 自动化测试

```powershell
npm run check
npm test
cargo test --manifest-path src-tauri/Cargo.toml
npm run build
```

当前自动化测试覆盖：

- 空间索引的视口查询、跨网格去重、大型容器和 5000 节点场景。
- 节点修改的撤销、重做以及剪贴板数据隔离。
- 缓存目录并发写入、工程缓存隔离、图片缓存复用及原图变化后的失效。
- 工程文件原子替换保存。
- 图片 HTML 属性解析与旧工程资源格式兼容。

## 发布前人工回归

- 鼠标中键连续平移，松开后画布不得跳动。
- 快速滚轮缩放时不闪烁、不显示远处高分辨率图片。
- 单节点和多节点拖动流畅，松开后位置、分组及撤销结果正确。
- 文本与图片跨画布复制粘贴，鼠标位于粘贴内容正中心。
- 涂鸦画笔、压感、箭头、矩形、圆形、撤销和一键清除均正常。
- 涂鸦随工程保存并恢复，但导出 PNG 时不出现涂鸦。
- 每个工程能够选择独立缓存目录；目录不可用时图片仍能通过系统缓存显示。
- 修改原始图片的大小或时间后重新生成缓存。
- 保存过程中强制关闭程序后，原工程仍能打开；再次打开时能够发现更新的恢复副本。
- PNG、JPG、WebP、TIFF、TGA、EXR、HDR、AVIF、PSD、PSB 等图片格式导入。
- OBJ、FBX、GLB、GLTF 模型导入、预览和资源释放。
- 文档、表格、PDF 和常见视频格式导入与显示。

## 性能基准建议

每个正式版本至少测试 500、2000、5000 个节点，以及 100、500、1000 张图片，记录首次打开时间、缓存命中后的打开时间、连续平移帧率、缩放响应和内存峰值。
