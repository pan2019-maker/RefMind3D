# RefMind3D 

面向设计师与 3D 创作者的高性能无限参考画布，用于统一整理图片、视频、文档、3D 模型、思维导图与创作灵感。

## fixed58 更新

- 大文件导入改为路径引用和轻量预览，不再把普通图片、模型、视频、文档整体转成 base64 常驻内存。
- 工程包保存仍支持嵌入资源，但资源从文件路径流式写入 zip；打开工程包时会解包资源并回填本地路径。
- Word `.docx` 导入新增富文本预览，支持常见标题、段落、粗斜体、下划线、颜色、表格和图片；双击文档节点可编辑富文本并导出 `.docx`。
- AI 面板改为点击打开/收起，不再依赖鼠标 hover，避免边缘闪烁。

## Windows 一键运行

打包 release exe：双击 `build-release.bat`。

## fixed8 更新

- PSD 导入优化：PSD 优先使用内置 Rust 解码器，失败后才走 ImageMagick 兜底，减少外部进程导致的等待。
- PSD/特殊格式不再额外生成缩略图，只生成画布预览，导入更快。
- DDS 加入导入入口：优先使用 `image` crate 解码，失败后尝试 ImageMagick；仍失败时会生成 DDS 占位预览，保证文件能进入工程流程。
- 3D 模型导入后支持双击进入独立 3D 预览界面。
- OBJ / FBX / GLB / GLTF 在独立预览界面支持 360° 旋转、缩放和平移。
- 右键菜单新增“模型 → 进入 3D 预览”。

## 说明

DDS 的生产文件差异很大，尤其是 BCn 压缩和 DX10 头的 DDS。当前版本会优先尝试真实解码；如果本机没有可用解码器且内置解码失败，会生成占位预览，但原始 DDS 文件会保留在工程资源目录中。

## fixed9 更新

## Fixed41 无缓存完整工程文件

- 导入图片、模型、视频、文档时，不再把资源复制到 AppData 或自定义缓存目录。
- 资源本体会直接作为 data URL 存在工程数据里。
- 保存 `.refmind3d` 时，默认直接保存包含资源本体的完整工程文件。
- 打开工程时不再把资源解包到临时目录，图片/视频/模型会直接从工程内嵌数据预览。
- 为兼容旧版 fixed39/fixed40 的封装工程，打开旧封装文件时会把旧的 embeddedResources 转成 data URL，不再解包到硬盘。
- 缺点：工程文件会明显变大，超大视频/模型会让保存和打开更吃内存；这是无缓存模式的代价。

- 在 fixed45 的单文件 ZIP 工程格式基础上继续优化体积。

## AI 接口介绍与使用规则

RefMind3D 将“内容分析”和“图片生成”作为两套独立接口配置，既可以连接本地 Ollama，也可以连接 OpenAI 兼容服务、豆包或自定义 HTTP 服务。AI 可以读取当前选中的文本、图片及节点信息，将分析结果写回画布；图片生成成功后，新图会直接插入当前画布，并可与参考图自动建立牵引线。

### 接口配置

- 在画布中右键打开“设置 → AI 接口”，分别配置分析模型和图片生成模型。
- 分析模型用于文字回复、内容整理和图片理解，可使用 Ollama 或 OpenAI 兼容的聊天/视觉模型。
- 图片生成模型用于文生图和参考图生成，必须使用真正支持图片生成的 Provider；视觉理解模型不能代替出图模型。
- API 地址应填写服务商提供的基础地址。OpenAI 兼容服务通常以 `/v1` 结尾；本地 Ollama 通常使用 `http://localhost:11434/v1`。
- 模型名称必须与服务端实际存在的模型完全一致。使用 Ollama 时，可通过 `ollama list` 查看模型，并通过 `ollama pull <模型名>` 安装缺少的模型。
- 配置完成后，先使用“测试连接”确认地址、密钥和模型有效，再开始正式调用。

### 使用方法

1. 在画布中选择需要分析的文本、图片或其他节点；视觉分析单次最多附加 4 张图片。
2. 打开左侧 AI 面板，输入要求。按 Enter 发送，使用 Shift+Enter 换行。
3. 点击“发送分析”进行文字或视觉分析；点击“生成图片到画布”调用图片生成接口。
4. 分析结果可以写回为文本或思维导图节点；生成的图片会插入当前画布，并自动定位。

### 使用规则与安全说明

- 不要把 API Key 写入 README、截图、项目文件或提交到 GitHub；仅在本机设置中保存自己的密钥。
- 请遵守所使用模型服务商的内容政策、授权条款、计费规则和速率限制。
- 发送分析时，选中节点的文字、元信息及所选图片可能会上传到配置的服务商；处理敏感资料前请确认服务商的数据与隐私政策。
- 本地 Ollama 适合离线分析，但只有已安装且具备视觉能力的模型才能看图；它默认不承担图片生成任务。
- 如果接口返回模型不存在、上下文超限或格式不兼容，请先核对模型名称、接口类型、基础地址及服务端能力。
- AI 输出仅作为创作辅助。发布或商用前，请人工检查内容准确性、版权和可用性。
