# RefMind3D

## v1.8.0 大型画布流畅度与稳定性

- 画布按背景、连接线、节点与涂鸦隔离绘制，低帧率时自动切换均衡或流畅优先级别。
- 图片按缩略图、中等图、预览图和原图渐进切换，解码完成后再替换画面，减少闪烁。
- 图片任务会根据设备内存和实时帧率自动调整并发，并沿画布移动方向提前加载。
- 超远坐标使用动态渲染原点，降低浮点误差造成的抖动、漂移和缩放跳跃。
- 鼠标、数位笔、裁切、涂鸦、框选、拖动和缩放使用互斥交互状态，避免状态串扰。
- 拖动节点时提供边缘与中心智能参考线；按住 Alt 可临时关闭吸附。
- 可见的链接素材每 5 秒检查大小和修改时间，变化后只刷新对应素材缓存，也可单独关闭自动刷新。
- 手动保存、定时保存和关闭前保存共用串行队列，防止旧快照覆盖新编辑；工程继续使用分画布数据与原子替换。
- 性能诊断新增帧时间、清晰度层级、纹理估算、缓存队列和源文件刷新统计，并可导出 JSON 报告。

## v1.7.0 深度参考工作流

- 双击图片进入画布内裁切编辑：拖动取景、滚轮缩放、八方向调整裁切框，Esc 完成。
- 链接资源自动检查失联状态，支持单项重新定位和批量按文件名匹配。
- 层级面板支持拖拽排序、拖入组建立父子关系、F2 重命名和资源状态标记。
- 排列工具新增紧凑智能装箱、按路径/添加时间/层级顺序排列、随机排列、堆叠及可调间距。
- 新增系统屏幕取色、颜色复制和图片原图坐标检查。
- 最近工程数量、启动页显示和自动打开最近工程均可配置。
- 演示模式支持可调间隔、层级顺序、随机不重复与完全随机，手动翻页自动暂停。
- 已保存工程支持定时覆盖保存；恢复中心记录自动恢复快照状态。
- 新增深色、浅色和玻璃主题，设置支持导入导出，快捷键冲突会立即标记。

## v1.6.0 参考工作流增强

- 图片支持非破坏式裁切画框、画面缩放/取景、水平/垂直镜像、透明度与灰度，原始文件不会被改写。
- 节点层级面板支持搜索、快速定位、显隐、锁定和逐层调整；画布支持整体锁定与灰度检查。
- 新增连续浏览/自动演示模式，可用方向键或 PageUp/PageDown 切换，Esc 退出。
- 新增导出中心，统一整张画布、选区 PNG、原始资源与便携工程副本的出口。
- 资源可逐个选择“嵌入工程”或“链接原文件”，在便携性与工程体积之间自由取舍。
- 空白启动页显示最近工程；排列工具新增按名称智能排列和统一视觉面积。
- PNG 导出与画布显示使用相同的显隐、透明度、灰度、镜像和裁切取景规则。

## v1.5.0 极端工程与交互优化

- v3 工程首次打开只读取工程索引和当前画布，其他画布切换时再从独立数据块加载。
- 平移、缩放和涂鸦继续使用合成层预览、合并指针事件与逐帧提交，减少交互状态更新。
- 根据设备内存、实时帧率和节点数量动态调节高清图片、视频与 3D 模型预算。
- 工程保存移入后台阻塞任务，画布界面不会等待压缩和磁盘写入。
- 图片缓存目录改用内容指纹，同一工程内重复来源直接复用解码结果。
- 图片根据显示尺寸自动升降预览等级，离开视野后释放实时模型和高清资源。
- 以单个画布定时器合并原始素材变化检查，避免大量文件监控事件形成刷新风暴。
- 每次保存保留最近 3 份轻量工程索引；工程包损坏时尝试读取最近索引备份。
- 性能诊断补充视口查询和 120 帧合成压力测试，并保留万人节点基准。

## v1.4.0 大型工程优化

- 非活动画布保持轻量序列化状态，切换时才恢复可编辑对象，并记忆每个画布最后视口。
- 撤销与重做改用按字段补丁，常见移动、缩放和文字编辑只记录节点字段集合。
- 空间索引增量同步，视口保留短时 DOM 节点池，快速往返平移减少反复挂载。
- 3D 预览离开视野后完整释放材质、纹理、渲染列表和 WebGL 上下文。
- 根据上次视口与移动方向进行附近节点预热，图片继续使用分级解码和并发预算。
- 自动恢复只写入上次手动保存后变化过的画布，未变化画布不进入恢复日志。
- 新建工程包采用 v3 分块结构，每张画布拥有独立 JSON 数据块；旧版工程继续兼容。
- 设置中的性能面板新增 10,000 节点基准测试，便于识别设备性能和版本回退。

## v1.3.0 性能与可靠性更新

- 非活动画布以序列化快照驻留，仅在切换时恢复对象，降低多画布工程的常驻内存。
- 撤销栈使用结构共享并按一次交互记录，避免拖动和输入过程中反复复制完整工程。
- 图片解码在 Rust 后台线程执行；视口资源按优先级调度，并限制并发解码数量。
- 已完成的涂鸦通过 OffscreenCanvas 工作线程绘制，当前笔画保持独立低延迟图层。
- 重复导入同一来源资源时复用已有资产记录，减少工程包体积。
- 3D 模型封面统一保存到当前工程缓存目录，可随工程缓存一起管理和清理。
- 更改缓存目录后后台迁移已有缓存，不阻塞画布继续操作。
- 节点数量过大时自动启用简化显示，关闭非必要阴影、标题和非选中模型实时渲染。
- 设置中新增工程健康检查，可发现失效资源引用、断裂连线、重复资源、空分组和超大文件。

RefMind3D 是面向设计师和 3D 创作者的无限参考画布，用于统一整理图片、视频、文档、表格、3D 模型、思维导图与创意资料。

## 主要能力

- 多画布工程以及图片、文本、视频、文档、表格和 3D 模型节点。
- 文本与图片节点支持跨画布复制、粘贴，并以鼠标位置为节点中心。
- 支持自由画笔、压感、箭头、空心矩形和空心圆形涂鸦；涂鸦保存在工程中，但不随图片导出。
- 每个工程拥有独立图片缓存目录，缓存可跨版本保留，默认容量上限为 10 GB。
- 支持本地 Ollama、OpenAI 兼容服务、豆包和自定义 HTTP AI 服务。

## v1.2.0 性能与可靠性

- 使用空间索引查询视野附近节点，大型画布移动时不再遍历全部节点。
- 画布平移与节点拖动采用合成层预览，操作结束后才提交工程状态。
- 涂鸦改由双 Canvas 图层绘制，已完成笔迹与当前笔迹分层渲染。
- 图片按照缩略图、缓存预览、原始分辨率三级渐进加载。
- 撤销历史采用结构共享，避免每次修改都完整复制大型工程。
- 工程脏状态使用轻量修订签名，不再在每次界面更新时序列化整个工程。
- 3D 引擎按需加载，明显缩小首屏 JavaScript 体积。
- 工程采用临时文件完整写入后原子替换，并为已保存工程生成不重复打包原始素材的轻量恢复快照。
- 工程指定的缓存目录暂时不可用时，图片加载会回退到系统缓存目录。

## v1.2.1 持续流畅优化

- 节点缩放期间使用 DOM 合成预览，松开鼠标后一次提交尺寸和字号。
- 图片缓存生成使用三级优先级队列，限制同时解码数量并取消失去全部消费者的排队任务。
- 前端图片缓存采用 LRU 淘汰；窗口隐藏时主动降级超高清图片。
- 涂鸦只重绘当前视野相交的笔迹，连线通过节点邻接索引获取。
- 自动恢复改为轻量 JSON 快照，恢复时复用正式工程资源，不再重复打包未变化素材。
- 清理同一素材失效的运行时缓存映射，控制长时间运行的内存增长。

## 开发

首次运行开发版可以双击 `run-dev.bat`，也可以执行：

```powershell
npm install
npm run tauri:dev
```

检查、测试和构建前端：

```powershell
npm run check
npm test
npm run build
```

运行 Rust 测试：

```powershell
cargo test --manifest-path src-tauri/Cargo.toml
```

生成 Windows 发布包可以双击 `build-release.bat`。

## 图片缓存

- 默认目录位于 `%LOCALAPPDATA%\RefMind3D\ImageCache\<工程缓存 ID>`。
- 用户可以在“设置 → 图片缓存”中为每个工程选择不同目录。
- 工程中的所有画布共用该工程的缓存目录。
- 原始文件大小或修改时间发生变化时，缓存自动失效并重新生成。
- 可以清理当前工程 30 天前的缓存或全部缓存；清理缓存不会删除工程和原始素材。
- 自定义目录不可用时，设置界面会提示重新选择，但图片会临时使用系统缓存继续加载。

## AI 接口与使用规则

“内容分析”和“图片生成”使用两套独立配置。内容分析用于文字回复、内容整理和图片理解；图片生成必须连接真正支持图像生成的服务。

1. 在画布中右键打开“设置 → AI 接口”。
2. 分别填写服务类型、API 地址、API Key 和模型名称。
3. 选择画布节点后使用“发送分析”，或使用“生成图片到画布”。
4. 单次视觉分析最多附带 4 张选中图片，以避免请求体过大。

使用第三方服务时，请遵守服务商的内容政策、授权条款、计费规则和速率限制。发送分析时，选中节点的文字、元信息和图片可能上传到所配置的服务；处理敏感信息前请确认服务商的数据与隐私政策。AI 输出仅作为创作辅助，发布或商用前应人工核对准确性、版权和可用性。
